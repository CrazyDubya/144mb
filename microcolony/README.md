# MICROCOLONY — beta

Complete three laboratory samples: pond balance, runoff recovery, and vent
diversity. Each sample has a different viable population band and must remain
stable for 100 simulation steps. A limited tool budget forces deliberate use of
nutrients and local antibiotics.

- Arrow keys: move the pipette
- Z: add nutrients
- X: apply local antibiotic
- H: hold for objective and controls; pauses play
- Enter: restart
- Escape: quit

Build with `./build.sh`. The Windows game includes population-driven synthesis.
Run `./build/microcolony_headless -N 100` for a seeded research sweep.
